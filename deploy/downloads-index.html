连接与提醒

桌面端可登录 HTTPS 服务器，也可使用需要 PostgreSQL 的本地模式。手机端连接服务器；系统通知需要授权。iOS 后台持续采集与远程推送尚未提供，关闭应用后不会持续轮询。

下载页默认使用 HTTP 8888 端口。工作台登录使用管理员提供的 HTTPS 地址。各平台安装包已构建验证；真机通知和系统安装体验仍需在目标设备验收。
