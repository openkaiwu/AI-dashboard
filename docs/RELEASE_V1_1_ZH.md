# AI Hub 正式版 v1.1

版本：Windows `1.1.0`，Android `1.1.0+4`。

## 更新内容

- Windows 开机启动后显示 Codex 额度页，恢复已保存的服务器模式和登录状态。
- 短暂网络故障自动重试；采集器配置变更后重新启动，避免重复进程。
- Windows 登录凭据使用 CurrentUser DPAPI 保护，安装身份独立于浏览器缓存持久化。
- 管理员页面显示各区块加载错误，保留审核后的申请，并正确识别过期邀请码。
- Android 包含当前移动端功能及四个固定额度消费面板。
- 安装包排除本机模式偏好、测试文件、凭据、私钥及运行日志。

## 产物

- `AIHub-正式版v1.1.exe`：Windows x64 NSIS 安装包。
- `AIHub-正式版v1.1.apk`：Android APK。
- `SHA256SUMS-v1.1.txt`：两个文件的 SHA-256 校验清单。

下载页及发布脚本仅使用相对下载链接或调用方提供的路径，不包含实际服务器地址、账户或密钥。

## 验证

- 桌面测试：19 项通过。
- Android 静态检查：无问题。
- Android 测试：13 项通过，2 项需要专用集成账号的测试跳过。
- 桌面打包版本、源码及文件排除规则核对通过；内置服务端和采集器从当前源码重新编译。
- Android 版本号为 `1.1.0`，构建号为 `4`；APK v2 签名校验通过，沿用原有签名证书。
- 发布脚本在安装前后校验文件哈希，并保留旧下载页和旧 APK 的备份。

## 验证边界

Windows 安装包尚无发布者 Authenticode 证书签名；Android 沿用现有调试证书，未使用应用商店发行证书。本轮没有进行安卓真机安装或 Windows 整机重启测试。
