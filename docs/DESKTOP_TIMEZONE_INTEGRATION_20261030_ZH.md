# AI Hub 内嵌时区切换

日期：2026-10-30。Windows 桌面端 1.1.13 在左侧“本机工具”新增“时区切换”，点击后在 AI Hub 右侧打开 `/timezone` 页面。两地时钟、当前电脑时区、切换按钮、执行结果和错误提示均显示在应用内部，支持浅深色主题及窄窗口。

组件复用已有 Windows 时区切换 v1.0.0 的底层逻辑，不打开独立工具窗口。后台 `--status` 只读 Windows 实际时区和 UTC 偏移；`--switch cn|la` 在用户点击城市按钮后切换、核验并返回结果。关闭自动时区时可能出现 Windows UAC 系统授权提示，由用户确认。保留自动校时、洛杉矶夏令时及失败回滚。

主进程只接受 `cn`/`la` 两个目标，不接受命令或程序路径。IPC 校验主窗口及其 origin，后台组件固定随安装包携带。切换期间拒绝重复请求；不会在授权/切换中途因主进程超时杀死组件。读取状态的请求设有超时。界面区分授权取消与成功，成功后使用 Windows 返回的实际偏移更新当前时钟，避免浏览器缓存旧时区。

源码：`apps/desktop/tools/timezone`；构建：`scripts/Stage-TimeZone-Tool.ps1`。原项目目录不是运行依赖。系统状态读取及本机切换无需云端会话有效。

验证：41 项桌面 Node 测试、44 项 Web 测试、TypeScript/生产构建及原组件 14 项时区/DST/DPI 检查通过。真实 Electron 测试覆盖侧栏内部导航、sandbox preload 到后台状态读取、模拟取消授权提示、390px 窄窗口无横向溢出；切换指令测试使用替身，不实际改系统时区。暂存界面及打包后资源执行真实 Electron 渲染检查。
