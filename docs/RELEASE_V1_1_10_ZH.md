# AI Hub v1.1.10 · 额度界面与提醒状态优化

日期：2026-10-25。Windows x64、Android 1.1.10（构建号 14）；其他平台继续提供 v1.1.4。

## 用户可见变化

- 总览缩短顶部留白，突出剩余额度，明确显示“数据截至”。时间只取观察时间，缺失或无效时显示“采集时间未知”。
- 电脑同步卡片集中显示采集时间、上次上传、待上传份数及自动同步开关；上传和切换设置期间禁用重复操作，较晚返回的旧状态不会覆盖操作结果。
- 安卓提醒设置集中显示通知条件、主提醒手机和后台任务。渠道关闭、权限拒绝、系统免打扰会直接说明原因；仅允许通知栏时不误称横幅已经就绪。后台、电池和诊断记录放入展开区。
- 刷新中保留已有额度；缓存写入失败时继续显示成功获取的新数据，同时单独提示保存失败。缓存错误不会把仍有效的数据误判成采集过期。
- 合并总览刷新请求，页面进入后台时暂停界面轮询，恢复时刷新；安卓切换账号后忽略旧请求结果，所选电脑被删除时自动回退到仍存在的电脑。

- 修正安卓版发布默认连接地址：发布脚本必须传入 HTTPS 服务器根地址，通过构建参数注入，避免新安装误连手机自身的 localhost。已有服务器配置继续保留。
