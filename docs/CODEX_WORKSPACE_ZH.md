# Codex 工作台功能分区

本次先分析现有页面：额度、提醒、外部消息和规则集中在同一页；原导航只是锚点；忽略或稍后处理后无法主动恢复。按日常使用流程拆为五个可直接打开、刷新和前进后退的标签，保留白色背景。

| 标签 | 功能 |
| --- | --- |
| 额度总览 | 真实额度、节奏建议、最近趋势、重置卡状态 |
| 使用计划 | 预留额度试算、未来 24 小时预算、重置与到期时间线、趋势 CSV 导出 |
| 提醒中心 | 待处理、稍后提醒、已忽略分类；恢复操作跨设备同步 |
| 重置雷达 | Tibo 原帖、检查时间和来源状态 |
| 提醒设置 | 阈值、免打扰、账户提醒开关、浏览器通知权限 |

电脑采集器、设备管理和跨端便笺保留独立入口。旧的 #reminders / #rules 链接仍可进入相应标签。

## 新增功能边界

- 预算以完整额度的百分点计算：可分配 = max(剩余 − 预留, 0)；未来 24 小时预算 = 可分配 × min(1, 24 / 剩余小时)。不会换算成任务次数或 token 数。所有并行窗口都需要分别满足预算。
- 预留滑块是临时试算，不写入账户规则；离开工作台后会恢复默认 10 个百分点。过期、缺失和不可用数据不生成预算。
- CSV 仅导出所选电脑最近最多 6 小时、最多 500 条已采集快照的窗口指标，无会话、提示词和凭据，文本单元格防公式注入。
- 提醒分类仅包含仍满足触发条件的事件，不是完整历史审计。恢复清除已忽略和稍后时间；通知仍受原有冷却和免打扰限制。
- 时间线以采集返回的时间为准，时间到达不会宣称已经重置。
- 五标签适用于桌面和移动浏览器；Flutter 原生页面仍使用原有布局。公网服务和手机后台推送尚未配置。
