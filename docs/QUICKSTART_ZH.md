# 三分钟试用

1. 运行 scripts/Start-Local.ps1，打开 http://127.0.0.1:8080。
2. 用 `aihub-admin --email 你的邮箱` 初始化首个管理员（密码通过标准输入提供），再由管理员创建普通账户。公开注册已关闭。
3. “跨端便笺”创建一条记录；保存后待上传归零即已同步到服务器。
4. “额度看板”查看已有手工管理功能；演示空间显示的是样例额度。
5. 每账户各绑定一台桌面和移动设备；换设备由管理员解绑。退出只撤销当前会话。
6. “切换服务器”管理 Server Profile。部署公网 HTTPS 后，手机打开同一地址即可跨网络使用。

停止：scripts/Stop-Local.ps1。配置和便笺不会删除。

运行包供其他机器使用时需先准备 PostgreSQL；它不包含本机数据库或密码。
开发与正式部署细节见 DEPLOYMENT_ZH.md。
