# AI Hub v1.1.5

本次更新 Windows x64 与 Android（构建号 9）。其他平台继续提供 v1.1.4。

## 提醒

- 送达记录按设备保存，电脑弹过不会阻止手机接收；已读、忽略和稍后提醒仍是账户事件状态。
- 同一周期的额度风险只自动提醒一次，阈值附近短暂恢复不生成重复事件；稍后提醒到期、新周期和风险升级可重新触发。
- 已送达的旧候选不会一直阻塞后续提醒。即使缺少重置时间，也能识别额度偏低或耗尽。
- Cursor 本地提醒遵循已保存的启用状态和阈值，并使用与服务器相同的周期标识。

## 本地保存与同步

Windows 在用户数据目录下的 `aihub-desktop/local-data/<服务器与用户标识哈希>/` 保存原始额度样本、小时统计、历史分析、规则与提醒状态。目录独立于安装路径，默认关闭自动上传。

消耗分析与提醒设置中的「立即同步到手机」上传当前额度及消耗统计备份；也可打开「自动同步到服务器」。手机从服务器读取并保存本地副本，网络不可用时可查看缓存。数据和缓存按账户、服务器隔离。同步不会把未修改的电脑设置覆盖到手机新修改的规则上。

自动同步会在登录令牌到期前续期，并与网页请求共用续期锁，避免长时间运行后停止同步，也避免同时刷新导致凭据重用。

Windows 覆盖安装保留用户数据。交互式卸载默认选择保留，只有明确选择删除才清理该应用用户目录；静默卸载、升级不清理。Android 覆盖安装保留数据；Android 10+ 标准卸载界面可选择保留应用数据，旧系统和部分厂商界面可能不提供此选项。

## Android 后台

在 Codex 或 Cursor 的提醒设置中开启「后台自动同步并提醒」，允许通知和横幅，并检查电池限制。原生 JobScheduler 持久任务请求约每 15 分钟执行一次；系统省电、休眠或强制停止会延迟，不保证即时远程推送。

后台授权为限定用途的 30 天凭据，使用 Android Keystore 加密，仅允许读取同步数据和操作送达回执；账户停用、设备撤销、会话失效后不可继续访问。重新打开应用可续期。

已修复 Android 兼容时间库不能解析服务器 `+08:00` 时间戳的问题；此前会把新数据误判为过期并跳过通知。

## 雷达

展示采集新鲜度、账户重置倒计时、连续样本中的额度回升、外部来源最近尝试与最近成功时间。检查失败时保留历史已核实消息；支持消息去重、最近 72 小时筛选和搜索。外部消息和采集空档均不直接推断账户已重置。

## 验收

- Web：36 项测试通过；桌面：26 项测试通过。
- 完整 Gate：Go race 测试、vet、Flutter analyze 和 25 项 Flutter 测试通过；另有 2 项需要专用凭据的 Flutter 集成测试跳过。
- 隔离 Electron 实测：默认关闭自动同步；本地统计经服务器传到手机；手机端已修改的规则未被覆盖。
- Android API 34 模拟器：真实发行 APK 注册持久任务，通过系统 JobScheduler 执行后台同步，系统通知记录确认高优先级额度耗尽提醒；后台进程回收后重复检查没有再次发布同一通知，覆盖升级保留配置和本地缓存。
- 本机覆盖安装核对版本 1.1.5.0，登录凭据及全部 14 个已有本地数据文件保持不变。
- 公开下载页的 Windows、Android 安装包均完整取回，按顺序重组后核对文件长度与整包 SHA-256，均与发布清单一致。

Windows 安装包未配置发布者签名；Android 沿用原调试签名，与 v1.1.4 证书一致。模拟器验证不能替代各品牌真机、省电策略和蜂窝网络验收。
