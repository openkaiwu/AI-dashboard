## 2026-10-25 基线缺口与本次进展

- 已修复：安装包内置 Web 构建产物，在原有 origin 提供界面，API 保留网络语义。避免把新版桌面界面依赖于云端部署，保持原有登录与 IndexedDB 存储域。
- 会话页没有桌面拖入、全文/项目筛选、离线详情缓存、JSONL 导出入口；导入轮询缺少生命周期清理和可恢复状态。
- 配置页只暴露 Claude → Codex，已有反向转换 API 未接入；原始配置在服务器做 Secret 分类，桌面还缺上传前的本地预览。
- 已实施：授权目录选择、暂停/恢复、采集观察时间和本机诊断。扫描拒绝符号链接逃逸；复制诊断采用字段白名单，排除原始日志、目录、服务器地址与账号标识。
- 多项协作/运维能力存在后端，但桌面入口、权限状态和错误反馈不完整。
