# AI Hub 1.1.11 发布记录

日期：2026-10-28。Windows x64 1.1.11；Android 1.1.11，构建号 15。沿用 Electron 与原有账户、存储和升级链路。

## 交付内容

- 桌面与安卓新增浅色、深色、跟随系统。选择保存在当前设备；安卓写入按顺序执行，防止快速切换后保存旧值；读取超时不阻塞应用启动，保存失败有明确反馈。
- 深色样式覆盖导航、额度、消耗图表、设置和提醒。安卓补充浅深色、360/390 逻辑宽度的布局回归。
- 安卓“立即检查”等待原生检查完成后展示本次结果；测试通知成功不再显示为错误。状态页在前台每 15 秒刷新，增加明确标注的应用内提示演示；提醒轮询恢复成功后清除对应旧错误。
- 桌面随包携带界面，在既有服务器 origin 提供静态文件，保留存储域。API 转发保留认证和错误状态，禁用旧 service worker 接管随包界面；Electron sandbox/contextIsolation 保持启用。
- 桌面控制台提供采集状态、观察时间、暂停/恢复、最多 8 个授权目录扫描。只返回配置元信息与密钥名称，不自动上传扫描内容。Go 扫描拒绝符号链接逃逸，使用有界输入输出。
- 复制诊断只导出运行事实，排除本地路径、原始日志、服务器地址与账号标识。修正复制失败误报成功、刷新覆盖操作结果和原生工具字节编码问题。
