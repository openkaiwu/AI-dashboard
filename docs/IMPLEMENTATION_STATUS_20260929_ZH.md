# AI Hub 实现状态（2026-09-29）

本文记录当前 `codex/m1-m2-account-binding` 分支的实现范围和验证边界。源码、构建产物、本地运行和公网可用是不同状态；以下状态不等同于正式验收。

## 已实现的功能

| 范围 | 实现情况 |
| --- | --- |
| 账户授权与隔离 | 管理员初始化、创建及禁用账户、重置密码、解绑设备；关闭公开注册。每个账户最多绑定一台桌面设备和一台移动设备。服务端按登录账户校验业务数据，解绑或禁用会撤销关联会话。 |
| 桌面后台 | 登录后连接服务器并启动 Codex/Cursor 采集；关闭窗口保留托盘，明确退出时停止。采集失败时退避重连，Bridge 使用受限的上报授权。 |
| M1 额度与提醒 | Codex/Cursor 自动采集和手工额度来源分开保存；额度快照、历史、手工录入、幂等重试、规则、提醒已读/忽略/稍后处理及跨端状态同步。缺失或过期数据不按零额度推断。 |
| Codex 套餐 | 按 300 分钟窗口识别五小时额度；Plus 展示对应额度和建议，Pro 排除该窗口及相关提醒，未知套餐提示补充信息。 |
| M2 连接器 | Codex/Cursor 连接器清单、桌面 Bridge、固定页面浏览器扩展示例、CSV/JSON 导入预览与字段校验、手工采集回退。固定页面样本与真实额度隔离存储。 |
| 双模式界面 | 桌面和安卓均可选择 Codex/Cursor；两种模式提供额度总览、使用计划、提醒中心、重置雷达和提醒设置。Cursor 只展示有依据的字段。 |
| 安卓端 | 模式与同步状态、额度及计划、提醒操作、雷达状态及原帖入口、规则控制、手工账户和额度录入、设备与 Bridge 状态、离线便笺及服务器配置。手机查看服务端快照，采集由已绑定桌面执行。 |

## 重置雷达

- Codex 页面与安卓页面按三小时检查周期展示状态，超过时限标记为过期；外部消息只供参考，不修改真实额度或重置时间。
- Bridge 从其配置文件所在目录读取 `codex-news.json` 并上报。生成文件的本机自动任务必须写入该目录；部署或迁移机器后需要单独核对任务配置。
- 本文没有重新实测 `tibo-codex` 自动任务是否已按每三小时执行，也没有重新核实 X 原帖。不能仅凭页面文字判定自动检查链路已运行。

## 本地验证记录

- 服务端 Go 单元和 API 集成测试、Web 构建及 Electron 主进程测试已在 M1/M2 开发阶段通过；详见 [M1/M2 实施记录](M1_M2_IMPLEMENTATION_20260928_ZH.md)。
- 安卓 Flutter 静态分析通过；测试 **10 项通过、2 项跳过**。跳过项需要预置真实服务器账户。
- Android `0.3.0+2` Release APK 已构建并完成签名校验，文件位于 `artifacts/android-native/aihub-mobile.apk`。该文件使用调试签名，不能作为应用商店发布包。
- 本地 `adb devices` 未发现手机或模拟器，因此没有完成手机安装、界面点击、通知、跨网络连接和后台行为的实机验证。Release APK 要求 HTTPS；本地 Debug APK 因 Flutter 调试引擎依赖下载超时，尚未构建成功。

## 仍未完成或待验证

- M1：完整账单字段、部分新建业务对象的离线同步、移动端系统通知与投递状态持久化。
- M2：完整统一运行器和回放框架、真实网页适配及扩展实测、文件路径安全边界、第三个平台、官方 API 接入。
- 安卓与桌面差异：文件导入、历史 CSV 导出、管理员后台、系统终止后的远程推送尚未加入安卓端；手机不直接读取桌面平台凭据。
- 公网 HTTPS、真实手机跨网络同步、断线恢复、管理员禁用及解绑的跨设备即时效果，以及正式 M1/M2 验收 Gate 仍待验证。
